# 转发 ROS 服务 API (Forwarded ROS Services API) {#forwarded-ros-services-api}

::: tip 本文档已重组
转发 ROS 服务不再作为独立的 API 单独记录，而是与其他服务一起按功能分组。请从[服务 API 总览](./services.md)开始，或直接前往各接口所在的页面：

- [建图](./services-mapping.md) —— 地图叠加层、动态交通信息、子图查询、SLAM 地图图片。
- [标定](./services-calibration.md) —— 清除陀螺仪刻度、校准顶升桅杆刻度基准。
- [系统与维护](./services-system.md) —— 主题列表、已发布主题名称。
:::
